1. 적용 범위와 계정

할 일과 메모를 Eisenhower Matrix로 정리하고 Focus에는 최대 두 개의 실행 항목을 둡니다. 위젯과 선택적 Apple Reminders 연동을 제공합니다.

tedyway 자체 계정은 만들지 않습니다. 기기 간 동기화를 사용할 때 사용자의 Apple ID와 private CloudKit이 사용됩니다.

2. 기기에서 처리·보관하는 데이터

  • 할 일 제목·메모·사분면·마감일·Focus/완료 상태·변경 시각과 연결된 Reminder 식별자
  • SwiftData 저장소, 앱·위젯 App Group 복사본, 설정과 Keychain의 임의 사용자 UUID
  • StoreKit 구매·후원 기능을 표시하기 위한 로컬 거래 상태

3. Apple 서비스와 private 데이터 경계

  • SwiftData 자료는 iCloud를 사용할 수 있을 때 사용자의 private CloudKit 데이터베이스와 동기화됩니다. 사용할 수 없으면 로컬 저장소로 계속 동작합니다.
  • 사용자가 허용한 경우 Apple Reminders에 QuadDo 목록과 알림을 만들고 갱신·삭제합니다.
  • WidgetKit, App Group, Push/CloudKit, Keychain과 StoreKit은 Apple 서비스 경계에서 동작합니다.

4. 외부 서비스와 전송

  • Firebase Remote Config 의존 코드가 있지만 GoogleService-Info.plist가 빌드에 포함된 경우에만 초기화됩니다. 현재 저장소에는 실제 설정 파일이 없으며, 할 일 본문을 Remote Config로 보내는 코드는 확인되지 않았습니다.
  • 실제 배포 바이너리에 Google 설정을 넣는 경우 Firebase의 진단·설치 관련 처리와 App Store 개인정보 답변을 다시 검증해야 합니다.
  • 광고·사용자 프로파일링 목적의 외부 전송은 현재 검증 범위에서 확인되지 않았습니다.

제공자 문서: Apple 개인정보 보호 · Google 개인정보처리방침

5. 이용 목적

위 데이터는 각 항목에 적은 앱 기능과 사용자의 선택을 처리하는 데 사용됩니다. 이 앱에 존재하지 않는 계정·동기화 목적이나 현재 구현에서 확인되지 않은 광고·추적·판매 목적을 이 문서가 새로 부여하지 않습니다.

6. 보관

  • 할 일은 사용자가 개별 삭제하거나 앱 저장소가 제거될 때까지 로컬 및 동기화 저장소에 남을 수 있습니다.
  • private CloudKit 자료, iCloud 동기화 Keychain UUID와 Reminders 항목은 앱 삭제 뒤에도 각 Apple 서비스에 남을 수 있습니다.
  • StoreKit 거래 기록은 Apple 계정·App Store 경계에서 관리됩니다.

7. 삭제와 사용자 선택

  • 앱에서 필요 없는 할 일을 개별 삭제합니다. Reminders 연동 항목은 Apple Reminders에서도 결과를 확인합니다.
  • 설정에서 Reminders 접근을 끄고 시스템 설정에서 권한을 철회합니다.
  • 앱과 위젯을 삭제해 로컬 App Group·앱 컨테이너 사용을 중단합니다.
  • private CloudKit, Keychain과 Reminders 자료는 Apple ID의 iCloud·암호 및 키체인·미리 알림 설정에서 별도로 확인합니다.
  • 현재 앱에는 모든 로컬·App Group·Keychain·private CloudKit 자료를 한 번에 지우는 기능이 없습니다.
  • 앱 삭제만으로 iCloud·Keychain·Reminders·StoreKit 자료까지 삭제됐다고 간주하면 안 됩니다.
  • tedyway 운영자는 사용자의 private CloudKit 데이터베이스나 Apple 계정 자료를 일반 서비스 DB처럼 직접 삭제할 수 없습니다.
