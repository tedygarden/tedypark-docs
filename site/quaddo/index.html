Apple 영역

SwiftData 자료는 iCloud를 사용할 수 있을 때 사용자의 private CloudKit 데이터베이스와 동기화됩니다. 사용할 수 없으면 로컬 저장소로 계속 동작합니다.

외부 서비스

Firebase Remote Config 의존 코드가 있지만 GoogleService-Info.plist가 빌드에 포함된 경우에만 초기화됩니다. 현재 저장소에는 실제 설정 파일이 없으며, 할 일 본문을 Remote Config로 보내는 코드는 확인되지 않았습니다.

앱 삭제, 운영자 서버 삭제, Apple 또는 외부 제공자 데이터 삭제는 서로 같은 작업이 아닐 수 있습니다. 이 앱에 실제로 해당하는 범위는 개인정보처리방침과 데이터 삭제 안내를 확인하세요.
