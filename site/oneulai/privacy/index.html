1. 적용 범위와 계정

보호자가 선택한 사진·동영상과 아이 프로필을 이용해 하루 기록과 AI 분석 결과를 만듭니다. AI 결과는 참고 정보이며 의료 진단이 아닙니다.

Sign in with Apple 또는 이메일 기반 계정을 사용하며 Supabase Auth에서 인증합니다. 아동은 직접 계정을 만들 수 없고, 성인 보호자가 자신의 계정으로 동의 후 관리해야 합니다.

2. 기기에서 처리·보관하는 데이터

  • 기기 사진 보관함의 원본은 Apple Photos에 남고, 앱은 권한 범위에서 선택한 미디어와 로컬 식별자·촬영 시각·포함된 GPS 메타데이터를 읽습니다.
  • 앱 설정, 인증 세션, 화면 캐시와 분석 진행 상태 일부가 기기 저장소·Keychain에 남을 수 있습니다.
  • 삭제 요청이 접수되면 앱은 로그아웃과 로컬 정리를 시도하며, 정리 오류를 완료로 숨기지 않습니다.

3. Apple 서비스와 private 데이터 경계

  • Sign in with Apple, Photos와 iCloud 공유 보관함, APNS 푸시, StoreKit 구매 기능을 사용할 수 있습니다.
  • iCloud 공유 보관함은 Apple이 운영하며 앱이 접근한 미디어도 사용자가 시작한 분석에서는 같은 Supabase Edge·Gemini 경로로 처리됩니다.
  • 사진 보관함 원본 삭제, Apple 계정과 App Store 거래 관리는 Apple 서비스 경계에서 이뤄집니다.

4. 외부 서비스와 전송

  • 현재 활성 내부 TestFlight 1.0 (260613.203453)은 다음 sol 후보보다 오래된 legacy build입니다. 선택한 미디어를 앱에서 Google Gemini로 직접 보낼 수 있고 Firebase Remote Config를 초기화할 수 있으므로, 회수·만료 또는 별도 검증 전에는 새 개인정보를 입력하지 않습니다.
  • Supabase Auth·Database: 이메일 또는 Sign in with Apple 계정 식별·인증 상태, 아이 이름·생년월일, 가족 공간·구성원, 보호자 동의, 촬영 시각·포함된 GPS 같은 미디어 메타데이터, AI 결과, 이용 이벤트·오류, 기기·APNS 정보와 구매·구독 상태를 인증·저장·조회합니다.
  • Supabase Edge Functions: 인증·소유권·현재 보호자 동의·삭제 계정 상태를 확인하고 AI 요청을 중계합니다. 사진은 인증된 분석 요청에 포함되어 Gemini로 전달되며 Supabase Storage에 별도 원본 객체로 저장하지 않습니다.
  • Supabase Storage: 동영상을 인증된 사용자 경로에 임시 업로드합니다. 정상·오류 처리 끝에 삭제를 시도하지만 실패·중단으로 남은 객체 정리와 완전 삭제는 아직 처음부터 끝까지 검증되지 않았습니다.
  • Google Gemini: 사용자가 분석을 시작한 사진·동영상, 필요한 아이 맥락과 프롬프트를 받아 AI 결과를 만듭니다. 정확한 제공자 보관 기간은 최종 계약·정책 검토 전 단정하지 않습니다.

제공자 문서: Apple 개인정보 보호 · Supabase 개인정보 안내 · Google Gemini API 이용약관 · Google 개인정보처리방침

5. 이용 목적

위 데이터는 각 항목에 적은 앱 기능과 사용자의 선택을 처리하는 데 사용됩니다. 이 앱에 존재하지 않는 계정·동기화 목적이나 현재 구현에서 확인되지 않은 광고·추적·판매 목적을 이 문서가 새로 부여하지 않습니다.

6. 보관

  • 계정·아이·가족·동의·AI 결과·이벤트·기기 자료는 기능 제공과 삭제 요청 처리에 필요한 동안 Supabase에 남을 수 있습니다. 항목별 확정 보관 기간과 운영 삭제 완료 기한은 아직 법무·운영 검증되지 않아 약속하지 않습니다.
  • 동영상은 분석을 위한 임시 Storage 객체이며 처리 종료 시 삭제를 시도합니다. 하지만 실패·중단된 객체의 정리와 계정 삭제 때의 전체 purge가 검증되지 않아 즉시 삭제를 주장하지 않습니다.
  • Google, Apple, Supabase가 자체적으로 처리하는 로그·거래·네트워크 정보는 각 제공자 정책을 따르며, tedyway 운영자가 확인하지 않은 국가·기간을 이 문서에서 추정하지 않습니다.

7. 삭제와 사용자 선택

  • 로그인한 앱의 설정에서 ‘계정 및 아이 데이터 삭제 요청’을 시작하고 확인합니다. 일반 경로는 이메일만 보내는 방식이 아닙니다.
  • 서버가 요청을 접수(HTTP 202)하면 계정은 AI 처리·데이터 변경·푸시 대상에서 동결되고, 앱은 로그아웃과 로컬 정리를 시도합니다.
  • 요청 상태나 앱 접근 문제가 있으면 같은 Apple 로그인 또는 가입 이메일을 식별할 수 있는 최소 정보로 지원 메일에 문의합니다. 비밀번호·인증 토큰·아동 미디어는 보내지 않습니다.
  • Apple Photos 원본, iCloud 공유 보관함, Sign in with Apple 연결과 App Store 구매 내역은 각각 Apple 설정에서 별도로 관리합니다.
  • 현재 요청 수락은 삭제 완료가 아닙니다. 서버 실제 삭제 작업(purge worker), 실패 재시도·실패대기열(dead-letter), 모든 테이블·Storage·Auth 삭제의 운영 증거가 아직 없습니다.
  • 따라서 즉시 삭제, 고정 완료 기한 또는 모든 백업·제공자 로그의 삭제를 보장하지 않습니다.
  • legacy TestFlight 회수·정책 정합성, 실제 E2E 증거와 수동 법무 검토가 끝날 때까지 새 TestFlight·App Store 업로드를 모두 차단합니다.
