출시 상태 고지

이 문서는 다음 sol 후보의 계약입니다. 현재 내부 TestFlight 1.0 (260613.203453)은 이전 구현으로, 앱에서 Gemini에 직접 미디어를 보내고 Firebase Remote Config를 초기화할 수 있어 이 문서와 동일한 흐름으로 간주하면 안 됩니다. 새 입력을 중지하고 legacy build를 회수하거나 별도 정책으로 덮은 뒤 검증해야 합니다. 동영상 임시 Storage 고아 객체 정리와 계정 삭제 purge worker의 E2E 증거도 없으므로 새 TestFlight·App Store 업로드를 모두 차단합니다.
