1. 적용 범위와 계정

시스템 음성 또는 사용자가 기기에서 만든 Personal Voice로 문장을 읽고, 선택적으로 온라인 신경망 음성을 사용할 수 있습니다.

계정을 만들지 않으며 tedyway 서버도 사용하지 않습니다. 마이크·연락처·위치 권한을 요청하지 않습니다.

2. 기기에서 처리·보관하는 데이터

  • 사용자가 입력·저장한 문구, 호칭, 말하기 히스토리와 재생 횟수
  • 음성·속도·음높이·개인정보 선택 등 설정과 위젯용 App Group 스냅샷
  • 온라인 합성으로 받은 MP3 캐시. 파일 보호가 적용된 Caches 영역에 저장됩니다.

3. Apple 서비스와 private 데이터 경계

  • 기본 시스템 음성은 AVSpeechSynthesizer로 기기에서 처리됩니다.
  • Personal Voice는 사용자가 Apple 설정에서 만든 음성을 권한 허용 후 사용하며 Apple이 기기에서 관리합니다.
  • 위젯은 App Group의 로컬 스냅샷을 읽으며 iCloud 동기화는 사용하지 않습니다.

4. 외부 서비스와 전송

  • 사용자가 현재 고지를 확인하고 명시적으로 동의해 온라인 음성을 켠 경우에만 실제 재생 문장 전체를 speech.platform.bing.com으로 전송합니다.
  • 전송 문장에는 직접 입력한 본문뿐 아니라 활성 호칭, 저장 문구, 히스토리 다시 말하기 내용이 포함될 수 있습니다.
  • 앱은 계정·광고 식별자·연락처·위치를 payload에 추가하지 않지만 Microsoft 측은 IP 주소와 요청 메타데이터를 처리할 수 있습니다. 정확한 보관 기간과 이용 범위는 확인되지 않았습니다.

제공자 문서: Microsoft Edge 데이터·개인정보 안내 · Apple 개인정보 보호

5. 이용 목적

위 데이터는 각 항목에 적은 앱 기능과 사용자의 선택을 처리하는 데 사용됩니다. 이 앱에 존재하지 않는 계정·동기화 목적이나 현재 구현에서 확인되지 않은 광고·추적·판매 목적을 이 문서가 새로 부여하지 않습니다.

6. 보관

  • 문구와 히스토리는 사용자가 앱에서 지우거나 앱 데이터가 제거될 때까지 기기에 남습니다.
  • 온라인 MP3 캐시는 설정의 캐시 삭제 기능으로 지울 수 있습니다.
  • Microsoft에 이미 전송된 문장·네트워크 정보의 보관 기간은 확인되지 않았으므로 즉시 삭제된다고 주장하지 않습니다.

7. 삭제와 사용자 선택

  • 설정에서 온라인 음성을 끄면 진행 중 합성을 취소하고 다시 켤 때 재동의를 요구합니다.
  • 설정에서 ‘온라인 음성 캐시 삭제’를 실행합니다.
  • 히스토리는 전체 삭제 또는 개별 삭제하고, 저장 문구·호칭도 앱에서 삭제합니다.
  • 남은 로컬 앱 데이터를 더 이상 쓰지 않으려면 앱과 위젯을 삭제합니다.
  • 계정과 tedyway 서버 저장본은 없으므로 운영자에게 계정 삭제를 요청할 대상이 없습니다.
  • 이미 Microsoft로 전송된 문장은 앱 캐시 삭제로 회수되지 않으며 tedyway 운영자가 대신 삭제할 수 없습니다.
  • Microsoft 처리·보관 범위와 비공식 endpoint 사용 권한은 프로덕션 출시 전 수동 확인 게이트입니다.
