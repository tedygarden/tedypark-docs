계정 상태: 계정을 만들지 않으며 tedyway 서버도 사용하지 않습니다. 마이크·연락처·위치 권한을 요청하지 않습니다.

출시 상태 고지

온라인 음성은 실험적 비공식 연동입니다. 독립 앱에서 speech.platform.bing.com을 사용할 수 있는지, 전송 데이터의 실제 보관·처리 범위가 확인되지 않았습니다. 이 근거가 해결되지 않으면 프로덕션에서 온라인 음성을 제거하거나 비활성화해야 하며, 해결 전 프로덕션 출시는 차단됩니다.

삭제·정리 순서

  1. 설정에서 온라인 음성을 끄면 진행 중 합성을 취소하고 다시 켤 때 재동의를 요구합니다.
  2. 설정에서 ‘온라인 음성 캐시 삭제’를 실행합니다.
  3. 히스토리는 전체 삭제 또는 개별 삭제하고, 저장 문구·호칭도 앱에서 삭제합니다.
  4. 남은 로컬 앱 데이터를 더 이상 쓰지 않으려면 앱과 위젯을 삭제합니다.

삭제되지 않거나 별도 조치가 필요한 영역

  • 계정과 tedyway 서버 저장본은 없으므로 운영자에게 계정 삭제를 요청할 대상이 없습니다.
  • 이미 Microsoft로 전송된 문장은 앱 캐시 삭제로 회수되지 않으며 tedyway 운영자가 대신 삭제할 수 없습니다.
  • Microsoft 처리·보관 범위와 비공식 endpoint 사용 권한은 프로덕션 출시 전 수동 확인 게이트입니다.

보관 경계

  • 문구와 히스토리는 사용자가 앱에서 지우거나 앱 데이터가 제거될 때까지 기기에 남습니다.
  • 온라인 MP3 캐시는 설정의 캐시 삭제 기능으로 지울 수 있습니다.
  • Microsoft에 이미 전송된 문장·네트워크 정보의 보관 기간은 확인되지 않았으므로 즉시 삭제된다고 주장하지 않습니다.
