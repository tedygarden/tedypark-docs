1. 적용 범위와 계정

앱에 포함된 지형 데이터를 이용해 자연 지형을 보존하며 도시를 건설합니다. 사용자가 허용하면 현재 위치에 가까운 수록 지도를 제안합니다.

계정과 개발자 운영 서버가 없습니다. 현재 검증한 앱 런타임은 네트워크 요청을 하지 않습니다.

2. 기기에서 처리·보관하는 데이터

  • 도시 건설 상태를 앱 Documents의 JSON 저장 파일에 보관합니다.
  • 스테이지 별점·진행도를 UserDefaults에 보관합니다.
  • 사용 중 위치 권한으로 약 100m 정확도의 현재 좌표를 한 번 받아 가까운 수록 지도와 위치 핀을 계산하며, 좌표는 현재 구현에서 파일로 저장하지 않습니다.

3. Apple 서비스와 private 데이터 경계

  • Core Location 권한은 ‘내 동네에서 시작’ 제안에만 사용합니다.
  • iCloud, CloudKit, Game Center 또는 외부 분석 서비스는 현재 앱 런타임에 연결되어 있지 않습니다.

4. 외부 서비스와 전송

  • 현재 검증한 앱 런타임에는 개발자 서버나 제3자 네트워크 전송 경로가 없습니다.
  • 지도 제작 도구는 개발 단계에서 OpenStreetMap·AWS Terrain Tiles 데이터를 사용하지만, 이 도구는 배포 앱에서 실행되지 않으며 사용자 위치를 보내지 않습니다.

5. 이용 목적

위 데이터는 각 항목에 적은 앱 기능과 사용자의 선택을 처리하는 데 사용됩니다. 이 앱에 존재하지 않는 계정·동기화 목적이나 현재 구현에서 확인되지 않은 광고·추적·판매 목적을 이 문서가 새로 부여하지 않습니다.

6. 보관

  • 게임 저장 파일과 별점은 사용자가 저장 슬롯을 덮어쓰거나 앱의 로컬 데이터가 제거될 때까지 기기에 남습니다.
  • 현재 위치는 메모리에서만 사용하고 게임 저장 파일에 넣지 않습니다.
  • 정확한 위치 권한 기록과 권한 선택은 iOS 시스템 설정에서 관리됩니다.

7. 삭제와 사용자 선택

  • iOS 설정에서 SeoulBuilder의 위치 권한을 ‘안 함’으로 바꿉니다.
  • 현재 앱에는 저장된 도시와 별점을 지우는 사용자 화면이 없으므로, 모든 로컬 자료를 정리하려면 앱을 삭제합니다.
  • 기기 백업에서 앱을 복원하면 운영체제 백업 정책에 따라 로컬 자료가 다시 복원될 수 있으므로 Apple의 백업 설정도 함께 확인합니다.
  • 현재 사용자 화면에는 도시 저장 파일이나 별점을 개별 또는 전체 삭제하는 기능이 없습니다.
  • 앱 삭제는 현재 좌표를 외부 서버에서 지우는 절차가 아닙니다. 현재 구현은 좌표를 서버나 저장 파일에 보내지 않습니다.
  • 앱 계정과 운영자 서버 저장본은 없으므로 이메일 계정 삭제 대상은 없습니다.
