1. 적용 범위와 동의

이 이용약관은 tedyway 운영자가 제공하는 Asanagram 무료 사내 베타의 이용 조건을 설명합니다. 앱에서 데이터 처리 안내에 동의하고 PAT를 연결하면 이 약관과 개인정보처리방침에 동의한 것으로 봅니다.

현재 배포는 소속 조직이 사용을 승인한 테스터에게만 허용되며 공개 판매, 일반 사용자 대상 서비스 또는 Asana의 공식 기능을 뜻하지 않습니다.

2. 이용 자격과 조직 승인

  • 이용자는 유효한 Asana 계정과 본인이 발급한 PAT를 사용하고, 해당 워크스페이스 데이터 처리에 필요한 조직 내부 승인을 받아야 합니다.
  • 본인에게 Asana에서 부여된 접근 권한을 넘는 데이터에 접근하거나 다른 사람의 PAT를 사용해서는 안 됩니다.
  • Asanagram은 공식 알림, 감사 로그, 법적 기록 보존 또는 인사 평가 시스템을 대체하지 않습니다.

3. 인증정보와 계정 보안

  • PAT는 비밀번호에 준하는 인증정보입니다. 메일, 메신저, 이슈 또는 지원 문의에 공유하지 말고 각 기기에서 직접 입력해야 합니다.
  • 분실·퇴사·권한 변경이나 의심스러운 접근이 있으면 앱에서 연결을 해제하고 Asana 개발자 설정에서도 PAT를 즉시 폐기합니다.
  • 이용자는 자신의 기기, Apple ID와 Asana 계정을 안전하게 관리할 책임이 있습니다.

4. 제공 기능과 사용자 작업

  • 앱은 Asana에서 이용자가 볼 수 있는 태스크, 댓글, 반응과 활동을 불러와 개인 피드로 재정렬합니다.
  • 댓글 작성, 좋아요와 완료처럼 Asana 원본을 바꾸는 작업은 이용자가 앱에서 명시적으로 실행한 경우에만 요청합니다.
  • 동기화 지연, API 제한 또는 앱 오류가 있을 수 있으므로 중요한 작업의 최종 상태는 Asana에서 확인합니다.

5. 데이터 처리와 삭제

  • 로컬 캐시, 기기별 Keychain PAT, Apple private CloudKit 상태, 외부 링크와 이미지 처리 범위는 개인정보처리방침을 따릅니다.
  • 배포 Release에서는 AI 요약·인물분석과 사용자 지정 백엔드를 비활성화합니다.
  • ‘이 기기 연결만 해제’와 ‘iCloud 동기화 데이터까지 삭제’를 구분합니다. 어느 쪽도 다른 기기의 로컬 자료·기기별 PAT나 Asana 원본을 원격 삭제하지 않으므로 각 기기와 Asana에서 별도로 정리해야 합니다.
  • Asana는 Asana 서비스 밖에서 Asanagram이 처리하는 사용자 콘텐츠의 개인정보 보호, 보안 또는 무결성을 책임지지 않습니다.

6. 금지 행위

  • 권한 없는 업무 데이터 수집·공유, 비밀정보의 외부 전송, 타인 감시·순위화 또는 인사 불이익 결정을 위해 앱을 사용해서는 안 됩니다.
  • Asana API 제한이나 보안 조치를 우회하거나 서비스 안정성을 해치는 자동화 요청을 해서는 안 됩니다.
  • Asana에서 얻은 사용자 콘텐츠를 권한 없는 제3자에게 판매·대여·공유하거나 AI 모델 학습·평가에 사용해서는 안 됩니다.

7. 베타 운영과 변경

  • 사내 베타에서는 기능, 데이터 형식과 제공 범위가 바뀌거나 일시 중단될 수 있습니다.
  • 중요한 데이터는 Asana를 원본으로 유지하며 앱 캐시를 유일한 백업으로 사용하지 않습니다.
  • 데이터 처리나 이용 조건이 실질적으로 바뀌면 공개 정책과 앱 안내를 갱신하고 필요한 경우 다시 동의를 받습니다.

8. 요금과 공개 서비스

현재 사내 베타는 무료이며 구독이나 앱 내 결제를 제공하지 않습니다. 공개 또는 유료 서비스는 OAuth, Asana의 필요한 승인, 법률 검토와 별도의 가격·결제 조건을 갖춘 뒤 새로 안내합니다.

9. 제3자 서비스와 비제휴

  • Asana 계정, API와 원본 데이터에는 Asana의 약관과 정책이 적용되고 Apple ID와 private CloudKit에는 Apple의 조건이 적용됩니다.
  • Asanagram은 독립 앱이며 Asana, Inc.와 제휴하거나 Asana가 보증하는 제품이 아닙니다. 데이터 출처는 Asana입니다.

10. 이용 중단과 문의

  • 조직 승인이 철회되거나 보안·법적 위험이 확인되면 이용을 중단하고 PAT를 폐기해야 하며, 운영자는 법령상 허용되는 범위에서 베타 제공을 제한하거나 종료할 수 있습니다.
  • 연결 해제와 데이터 삭제 순서는 데이터 삭제 안내를 따릅니다.
  • 지원과 정책 문의는 hi.k.ai@icloud.com으로 받습니다. 문의에는 PAT나 업무 원문을 포함하지 마세요.
