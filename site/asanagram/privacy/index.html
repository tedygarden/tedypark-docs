1. 적용 범위와 계정

Asana에서 사용자가 볼 수 있는 태스크, 댓글, 반응과 팀 활동을 불러와 읽음 상태·북마크·개인 그룹과 함께 보여줍니다.

tedyway 자체 계정은 만들지 않습니다. Asana 계정과 Personal Access Token(PAT)이 필요하며, 기기 간 동기화를 켜면 사용자의 Apple ID가 사용됩니다.

2. 기기에서 처리·보관하는 데이터

  • Asana 태스크 이름·설명, 댓글 본문, 작성자·담당자·프로젝트·첨부·반응 정보와 AI 생성 결과를 포함한 화면 표시용 캐시
  • 읽음 기록, 최근 본 항목, 북마크, 고정한 사람·그룹과 앱 설정
  • macOS Application Support의 캐시와 기기 내 UserDefaults 폴백
  • Core Spotlight 시스템 검색 설정은 이 기기에서 기본적으로 꺼져 있고 iCloud로 동기화되지 않습니다. 사용자가 명시적으로 켜고 사용 가능한 Asana 토큰이 있을 때에만 현재 캐시에서 중복을 제거한 최대 2,000개 항목의 태스크 이름·본문·댓글, 활동·작성자·프로젝트와 Asana 링크를 색인합니다.

3. Apple 서비스와 private 데이터 경계

  • PAT는 Apple Keychain의 동기화 항목으로 저장될 수 있습니다.
  • 읽음·고정·그룹·북마크 상태는 사용자의 private CloudKit 데이터베이스와 iCloud KVS에 동기화될 수 있습니다.
  • private CloudKit 데이터는 해당 Apple ID의 영역이며 tedyway 운영자가 일반 서비스 DB처럼 조회하거나 직접 지울 수 없습니다.

4. 외부 서비스와 전송

  • Asana API: PAT 권한 범위 안의 워크스페이스·사용자·팀과 태스크 이름·설명, 댓글 본문, 첨부·반응 정보를 조회하고, 사용자가 명시적으로 실행한 댓글·좋아요·완료 등의 작업을 반영합니다.
  • 선택적 macOS AI: 사용자가 별도 동의하고 기능을 실행하면 태스크·댓글 맥락이 기기에 설치된 Claude, Codex 또는 Gemini CLI로 전달됩니다. 실제 처리는 사용자가 선택한 Anthropic, OpenAI 또는 Google CLI의 로그인·설정과 해당 제공자 정책을 따릅니다.
  • 고급 설정에서 사용자가 별도 백엔드 URL을 지정한 경우 Asana 요청이 그 주소를 경유할 수 있습니다. 기본 경로는 Asana API 직접 연결입니다.

5. 이용 목적

위 데이터는 각 항목에 적은 앱 기능과 사용자의 선택을 처리하는 데 사용됩니다. 이 앱에 존재하지 않는 계정·동기화 목적이나 현재 구현에서 확인되지 않은 광고·추적·판매 목적을 이 문서가 새로 부여하지 않습니다.

6. 보관

  • 로컬 캐시는 앱 기능 제공과 오프라인 표시를 위해 기기에 남으며 앱 삭제 또는 해당 저장소 정리의 영향을 받습니다.
  • 일부 읽음 항목은 앱 정책상 60일·최대 5,000개로 정리되지만, 다른 북마크·그룹·캐시 전체에 동일한 기간을 약속하지 않습니다.
  • Core Spotlight 조정은 앱 시작·새로고침·더 불러오기 때 같은 기존 도메인의 삭제를 먼저 요청한 뒤, 명시적 동의와 Asana 토큰이 모두 있으면 현재 캐시에서 중복을 제거한 최대 2,000개 항목으로 교체합니다.
  • 각 Core Spotlight 항목의 만료일은 해당 조정 시점부터 30일입니다. 색인과 삭제는 기기의 Core Spotlight에 보내는 비동기 요청이므로 실제 기기에서 최종 결과를 확인해야 합니다.
  • Asana 원본 데이터와 선택한 AI 제공자의 처리는 각 제공자 정책을 따릅니다. tedyway 운영자가 그 보관 기간을 대신 보증하지 않습니다.

7. 삭제와 사용자 선택

  • 앱 설정에서 시스템 검색을 끄면 기기 로컬 opt-out이 먼저 저장되고 같은 Core Spotlight 도메인의 삭제가 요청됩니다. 삭제 실패는 설정 화면에 표시되며 다음 앱 시작·새로고침 같은 후속 조정에서 다시 시도합니다.
  • 앱에서 토큰을 교체하거나 ‘토큰 삭제’를 실행해도 시스템 검색 opt-out을 먼저 저장하고 색인 삭제를 요청합니다. 이 작업들은 순서대로 직렬 처리되어 마지막 비활성화 상태가 삭제 요청으로 수렴하도록 합니다.
  • ‘토큰 삭제’는 현재·이전 서비스 이름의 Keychain 항목을 모두 삭제하려고 시도하고, macOS의 ASANA_PAT 환경변수와 .env 자동 사용을 명시적 토큰 저장 전까지 계속 차단합니다. 앱은 외부 환경변수나 .env 파일 자체를 지울 수 없으므로 필요하면 사용자가 직접 제거합니다.
  • Asana 개발자 설정에서도 해당 PAT를 별도로 폐기합니다.
  • 앱에서 북마크·그룹·최근 본 기록처럼 개별 삭제 기능이 있는 항목을 정리합니다.
  • 시스템 검색을 끈 뒤 Spotlight 결과가 사라졌는지 실제 기기에서 확인합니다. Core Spotlight 삭제는 동기적 삭제 보장이 아니라 기기에 보내는 비동기 요청입니다.
  • 기기의 앱을 삭제하면 앱 컨테이너의 로컬 캐시는 더 이상 앱에서 사용할 수 없습니다.
  • private CloudKit와 iCloud Keychain 자료까지 정리하려면 Apple ID의 iCloud·암호 및 키체인 설정에서 해당 앱 데이터를 별도로 확인합니다.
  • 현재 앱에는 로컬 캐시·앱 설정·Core Spotlight·Keychain·iCloud KVS·private CloudKit 데이터를 한 번에 모두 지우는 기능이 없습니다.
  • Core Spotlight 삭제 요청이 실패하면 앱이 오류를 표시하고 이후 조정에서 재시도하지만, 완료 여부는 실제 기기에서 확인해야 합니다. 시스템 검색이 꺼져 있거나 토큰이 없으면 앱은 Spotlight 검색 결과의 열기 요청도 무시합니다.
  • 토큰 삭제는 현재·이전 Keychain 서비스의 정리를 시도하지만 실패할 수 있습니다. 앱은 macOS 프로세스 환경변수와 사용자 파일 시스템의 .env 파일 자체를 삭제할 권한이 없습니다.
  • 앱 삭제만으로 Keychain 또는 private CloudKit 데이터까지 삭제됐다고 간주하면 안 됩니다.
  • Asana에 원래 존재하는 태스크·댓글은 Asana에서 관리해야 하며, 지원 메일로 private CloudKit 또는 Asana 계정 데이터를 대신 삭제할 수 없습니다.
