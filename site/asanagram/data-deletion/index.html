삭제·정리 순서

  1. 앱 설정에서 ‘토큰 삭제’를 실행하고 Asana 개발자 설정에서도 해당 PAT를 폐기합니다.
  2. 앱에서 북마크·그룹·최근 본 기록처럼 개별 삭제 기능이 있는 항목을 정리합니다.
  3. 시스템 검색에 태스크 내용이 노출될 수 있으므로 앱 삭제 뒤에도 Spotlight 결과가 남는지 확인합니다. 현재 앱 안에는 색인 전체 삭제 버튼이 없습니다.
  4. 기기의 앱을 삭제하면 앱 컨테이너의 로컬 캐시는 더 이상 앱에서 사용할 수 없습니다.
  5. private CloudKit와 iCloud Keychain 자료까지 정리하려면 Apple ID의 iCloud·암호 및 키체인 설정에서 해당 앱 데이터를 별도로 확인합니다.

삭제되지 않거나 별도 조치가 필요한 영역

  • 현재 앱에는 로컬·Core Spotlight·Keychain·iCloud KVS·private CloudKit 데이터를 한 번에 모두 지우는 기능이 없습니다.
  • Core Spotlight에는 태스크 이름·설명·댓글이 시스템 검색용으로 자동 색인되며, opt-in 또는 앱 안 전체 삭제 기능이 없습니다.
  • 앱 삭제만으로 Keychain 또는 private CloudKit 데이터까지 삭제됐다고 간주하면 안 됩니다.
  • Asana에 원래 존재하는 태스크·댓글은 Asana에서 관리해야 하며, 지원 메일로 private CloudKit 또는 Asana 계정 데이터를 대신 삭제할 수 없습니다.

보관 경계

  • 로컬 캐시는 앱 기능 제공과 오프라인 표시를 위해 기기에 남으며 앱 삭제 또는 해당 저장소 정리의 영향을 받습니다.
  • 일부 읽음 항목은 앱 정책상 60일·최대 5,000개로 정리되지만, 다른 북마크·그룹·캐시 전체에 동일한 기간을 약속하지 않습니다.
  • Core Spotlight 색인은 현재 만료일 없이 남으며 앱에 명시적 색인 전체 삭제·재조정 기능이 없습니다.
  • Asana 원본 데이터와 선택한 AI 제공자의 처리는 각 제공자 정책을 따릅니다. tedyway 운영자가 그 보관 기간을 대신 보증하지 않습니다.
