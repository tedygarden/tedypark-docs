Asanagram 확인 사항

  • 문의 메일에 PAT, 회사 기밀, 태스크 본문이나 인증 토큰을 넣지 마세요.
  • Asana 권한 오류는 PAT가 해당 워크스페이스를 볼 수 있는지와 토큰 폐기 여부를 먼저 확인해 주세요.
  • iPhone↔Mac 동기화 문제는 두 기기의 Apple ID·iCloud 상태, 현재 Asana 워크스페이스와 앱 버전을 알려 주세요. PAT 자체는 기기 간 동기화하지 않습니다.
  • iCloud 동기화 데이터 삭제가 완료되지 않았다는 문구가 보이면 네트워크와 Apple ID 상태를 확인한 뒤 해당 기기에서 다시 시도하세요. 로컬 연결만 끝내려면 삭제 범위에서 ‘이 기기 연결만 해제’를 선택하세요.
  • 시스템 검색 삭제 실패 문구가 보이면 앱 시작 또는 새로고침 뒤 다시 확인하고, 업무 내용이 Spotlight에 남는지 실제 기기 검색 결과를 함께 확인해 주세요.
